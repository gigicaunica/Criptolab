01 · Cifra de substituição

Desloque as letras do alfabeto para codificar ou decodificar uma mensagem. Acentos, espaços e símbolos são preservados.

Codificar mensagem

Escolha um deslocamento e transforme seu texto.

Sua mensagem codificada aparecerá aqui.

Decodificar mensagem

Use o mesmo deslocamento para recuperar o texto original.

O texto decodificado aparecerá aqui.
Importante: a cifra de César é simples e insegura para proteger dados reais. Ela serve para aprender o conceito de substituição.

02 · Gerador de hash SHA-256

Um hash gera uma impressão digital do conteúdo. Mesmo pequenas mudanças na entrada normalmente produzem um resultado bem diferente.

O hash será exibido aqui.

Este exemplo usa a API Web Crypto do navegador. Hash não é criptografia reversível e, sozinho, SHA-256 não é a forma indicada para armazenar senhas.

03 · Simulador de força bruta

Veja, em um exemplo limitado, quantas combinações uma senha curta pode ter. O simulador calcula o espaço de busca; não tenta invadir contas nem serviços.

O cálculo aparecerá aqui.

A estimativa considera todas as combinações possíveis, não a velocidade de um equipamento específico.

04 · Boas práticas

🔑 Senhas únicas

Use uma senha diferente para cada serviço e prefira frases longas.

🛡️ Autenticação em dois fatores

Ative uma segunda etapa de verificação sempre que possível.

🧩 Atualizações

Mantenha sistema, navegador e aplicativos atualizados.

Nunca compartilhe senhas reais neste site. Os exemplos são para fins educacionais.
